❓ Comment ça marche ? (aide)▼
  1. Joueur A appuie sur 🎲 Nouveau code puis 📲 Envoyer à mon ami (SMS, WhatsApp…).
  2. Joueur B ouvre le lien reçu (le code se remplit tout seul) ou tape le code dans 🅱️ J'ai reçu un code.
  3. Quand l'ami apparaît en vert ✅, vous êtes connectés.
  4. Chacun choisit son deck, puis appuie sur ✋ Je suis prêt. Le duel se lance automatiquement.
  5. Pendant la partie, chacun joue à son tour : le bandeau indique à qui c'est de jouer.

💡 Ton ami n'apparaît pas ? Vérifiez que le code est identique, que vous avez Internet, et gardez l'onglet Multi ouvert sur les deux appareils.
